# Butter Music Player

**Офлайн-плеер для Android с большими возможностями: плейлисты, редактор трека с несколькими участками, 18-полосный эквалайзер, эффекты, визуализации и встроенный редактор тегов.**

## Возможности

### Библиотека и плейлисты
- Сканирование музыки на устройстве через `MediaStore`: **MP3, FLAC, OGG/Opus, M4A/AAC, WAV, MKA** и всё остальное, что умеет декодировать Android.
- **Плейлисты**: создание (＋), переименование и удаление (долгое нажатие на вкладку), добавление треков (долгое нажатие на трек), поиск.
- Кнопка **«Добавить музыку»** внутри плейлиста: можно выбрать **несколько файлов** или **целую папку** (с подпапками).
- **`<AutoName>`** — название нового плейлиста по умолчанию. Если добавить в него папку, плейлист получит имя этой папки.
- **Отключение треков**, как в AIMP: отключённый трек (☐) остаётся в плейлисте, но пропускается при воспроизведении.
- **Импорт списков** из Spotify (CSV из Exportify), экспорта SoundCloud, Google Takeout (YouTube Music), текстового файла «Исполнитель - Название» или JSON с подбором треков из музыки на устройстве. Не найденные треки показываются списком, нажатие открывает поиск в Spotify / SoundCloud / YouTube Music.

### Редактор тегов
- Название, исполнитель, альбом, год, номер трека, жанр.
- Запись для **MP3 (ID3v2.3 / 2.4)** и **FLAC (Vorbis comment)**. Обложка и остальные теги сохраняются, меняются только изменённые поля.
- Остальные форматы воспроизводятся, но редактировать их теги нельзя.

### Звук
- 18-полосный эквалайзер с пресетами, цепочка эффектов, автоматизация параметров.
- Жёсткий лимитер с потолком, мягкий клиппер, предусилитель, автоматический запас под усиление эквалайзера, режим моно.
- Скорость 0.5–2× с сохранением высоты тона.
- Таймер сна с плавным затуханием за 10 секунд.

### Редактор трека
- Форма волны, **несколько участков («дропов»)**: рисуются прямо по волне или задаются метками A/B во время прослушивания, границы можно перетаскивать, есть «играть только выделенное».
- Бесшовный повтор трека или выделенных участков, пока открыт редактор.
- Настройки каждого трека хранятся в JSON.

### Визуализации
Столбики · осциллограф · аналоговые VU-метры · свои линии (количество, толщина, цвет, градиент, радуга, зеркало, пики, скругление). Нажатие на визуализацию показывает обложку, долгое нажатие переключает режим.

### Прочее
- Темы: тёмная, светлая, AMOLED, своя с выбором цветов. Языки: English, Українська, Русский (или как в системе).
- Аудиофокус (пауза при звонке, приглушение), пауза при отключении наушников, уведомление с кнопками и `MediaSession` (кнопки гарнитуры).
- Восстановление последнего трека и позиции при запуске.

## Приватность

- **Нет разрешения на интернет**, нет аналитики и рекламы. Всё остаётся на устройстве.
- Разрешения: доступ к аудио (`READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE`), уведомления и foreground-служба для воспроизведения, а также `WRITE_EXTERNAL_STORAGE` на Android 9 и старше (только для правки тегов). На Android 10+ система просит подтверждение перед изменением тегов файла.

## Сборка

Нужно: Android Studio Koala (2024.1) или новее, JDK 17, Android SDK 34.

```bash
git clone https://github.com/blubby-Jr/butter-music-player.git
```

1. Откройте папку `Ver0.2.0` в Android Studio (**File ▸ Open**) и дождитесь Gradle Sync.
2. Запустите на устройстве (Android 8.0+, отладка по USB) или в эмуляторе.
3. APK: **Build ▸ Build APK(s)** → `app/build/outputs/apk/debug/`.

Из командной строки (Gradle 8.7):

```bash
cd Ver0.2.0
gradle assembleDebug
```

> Gradle wrapper (`gradlew`, `gradle-wrapper.jar`) в репозиторий не включён. Если нужен `./gradlew`, один раз выполните `gradle wrapper --gradle-version 8.7` (или дайте Android Studio сгенерировать его).

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `Core.kt` | Состояние, очередь воспроизведения, аудиофокус, таймер сна |
| `PlayerEngine.kt` | `MediaCodec` → DSP → `AudioTrack` |
| `Dsp.kt`, `Fft.kt` | Эквалайзер, эффекты, лимитер, спектр |
| `Selection.kt`, `Automation.kt`, `TrackSettings.kt` | Участки, автоматизация, JSON трека |
| `Library.kt` | Сканирование `MediaStore`, плейлисты (с отключёнными треками) |
| `PickImport.kt` | Сопоставление выбранных файлов и папок с треками библиотеки |
| `TagEditor.kt` | Запись ID3v2 и Vorbis comment |
| `ImportParser.kt` | Парсеры импорта плейлистов |
| `Views.kt`, `MainActivity.kt`, `Theme.kt`, `S.kt`, `AppSettings.kt` | Интерфейс, темы, локализация, настройки |
| `PlaybackService.kt` | Foreground-служба, уведомление, `MediaSession` |
| `tools/generate_icon.py` (в `Ver0.2.0/`) | Генератор иконки (`python3 tools/generate_icon.py [seed]`, нужен Pillow) |

## Чего не будет

- Скачивания и записи треков из Spotify, SoundCloud, YouTube Music (нарушает их условия и авторское право). Есть только импорт списков и ссылки на поиск.
- Импорта лайков «в один клик» (нужен вход в аккаунт и ключи разработчика API) — используйте экспорт в файл.
- Кроссфейда, DSD, скинов и визуализаций AIMP (это Windows-DLL).
