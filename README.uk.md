# Butter Music Player

**Офлайн-плеєр для Android з великими можливостями: плейлисти, редактор треку з кількома ділянками, 18-смуговий еквалайзер, ефекти, візуалізації та вбудований редактор тегів.**

## Можливості
- **Плейлисти**: створення (＋), перейменування й видалення (довге натискання на вкладку), додавання треків (довге натискання на трек), пошук по списку.
- **Додати музику** у плейлист: кнопка під вкладками (файли — кілька одразу, або ціла папка з підпапками). Плейлист з назвою `<AutoName>` (значення за замовчуванням) після додавання папки отримує її ім'я.
- **Вимкнення треків** у плейлисті (як в AIMP): довге натискання на трек → «Вимкнути в цьому плейлисті». Вимкнені (☐) пропускаються при відтворенні; «Увімкнути всі треки» — у меню вкладки.
- **Формати**: усе, що декодує Android (MP3, FLAC, OGG/Opus, M4A/AAC, WAV, MKA…).
- **Редактор тегів** (довге натискання на трек): назва, виконавець, альбом, рік, трек №, жанр. Запис підтримано для MP3 (ID3v2.3/2.4) і FLAC (Vorbis comment); обкладинка й інші теги зберігаються.
- **Налаштування**: мова (English за замовчуванням, автовизначення, українська, російська), теми (темна, світла, AMOLED, власна з вибором кольорів),
  звук (жорсткий лімітер зі стелею, м'який кліпер, пре-ампліфікація, авто-запас під підсилення EQ, моно), візуалізація (частота оновлення 10–90 fps, згладжування), таймер сну.
- **Повтор в Editor**: поки відкритий Editor, трек (або виділені ділянки) грає по колу безшовно.
- **Панель як у Telegram**: час, гучність, порядок (звичайний/зворотний/випадковий), повтор (вимк./список/трек), швидкість 1X (0.5–2X, висота тону зберігається), закрити.
- **Іконка** процедурно згенерована (екран осцилографа): `tools/generate_icon.py [seed]` перегенерує її з іншим seed.
- **Візуалізації**: 1) стовпчики, 2) осцилограф, 3) аналогові VU-вимірювачі, 4) власні лінії (кількість, товщина, колір, градієнт, веселка, дзеркало, піки, закруглення).
  Тап по візуалізації — обкладинка (якщо її немає — процедурна картинка), довгий тап — наступний режим.
- **Кілька ділянок (дропів)** в Editor: малювання виділення по хвилі, або A/B під час прослуховування; межі можна перетягувати; «грати лише виділене».
- **Імпорт списків** (Spotify CSV з Exportify, експорт SoundCloud, Google Takeout для YouTube Music, TXT «Виконавець - Назва», JSON) із зіставленням з музикою пристрою
  і створенням плейлиста; відсутні треки — списком, тап відкриває пошук у Spotify/SoundCloud/YouTube Music.
- **Додатково**: аудіофокус (пауза при дзвінку, приглушення), пауза при відключенні навушників, сповіщення з кнопками і MediaSession (кнопки гарнітури),
  відновлення останнього треку й позиції, пресети EQ, затухання перед таймером сну.

## Приватність

- **Немає дозволу на інтернет**, немає аналітики та реклами. Усе залишається на пристрої.
- Дозволи: доступ до аудіо (`READ_MEDIA_AUDIO` / `READ_EXTERNAL_STORAGE`), сповіщення та foreground-служба для відтворення, а також `WRITE_EXTERNAL_STORAGE` на Android 9 і старіших (лише для правки тегів). На Android 10+ система просить підтвердження перед зміною тегів файлу.

## Збірка

Потрібно: Android Studio Koala (2024.1) або новіша, JDK 17, Android SDK 34.

```bash
git clone https://github.com/blubby-Jr/butter-music-player.git
```

1. Відкрийте папку `Ver0.2.0` в Android Studio (**File ▸ Open**) і дочекайтесь Gradle Sync.
2. Запустіть на пристрої (Android 8.0+, налагодження по USB) або в емуляторі.
3. APK: **Build ▸ Build APK(s)** → `app/build/outputs/apk/debug/`.

З командного рядка (Gradle 8.7):

```bash
cd Ver0.2.0
gradle assembleDebug
```

> Gradle wrapper (`gradlew`, `gradle-wrapper.jar`) у репозиторій не включено. Якщо потрібен `./gradlew`, один раз виконайте `gradle wrapper --gradle-version 8.7` (або дайте Android Studio згенерувати його).

## Чого не буде
 (свідомо)
- **Завантаження/запис треків зі Spotify, SoundCloud, YouTube Music** — не підтримується (порушує їхні умови та авторське право). Є імпорт списків і пошук.
- Прямий імпорт лайків «в один клік» вимагає входу в акаунт через офіційні API (ключі розробника) — не реалізовано; використовуйте експорт у файл.
- Кросфейд, DSD (потрібен окремий декодер), візуалізації/скіни AIMP 4.50 (це Windows-DLL).

## Структура
`Core.kt` (стан, черга, аудіофокус, таймер сну) · `PlayerEngine.kt` (MediaCodec → DSP → AudioTrack) · `Dsp.kt` (EQ, ефекти, лімітер) ·
`Selection.kt` (кілька ділянок) · `Automation.kt` · `TrackSettings.kt` (JSON треку) · `AppSettings.kt`/`Theme.kt`/`S.kt` (налаштування, тема, переклади) ·
`Library.kt` (MediaStore, плейлисти) · `PickImport.kt` (вибір файлів і папок) · `TagEditor.kt` (ID3v2, Vorbis comment) · `ImportParser.kt` · `Views.kt` · `MainActivity.kt` · `PlaybackService.kt`.
